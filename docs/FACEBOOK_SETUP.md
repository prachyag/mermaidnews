# คู่มือเชื่อมต่อ Facebook Page กับ News Curator

คู่มือนี้พาทำตั้งแต่ศูนย์จนระบบโพสลงเพจได้จริง ใช้เวลาประมาณ 15–30 นาที

> 🙋 **ไม่อยากยุ่งกับ token/Page ID เลยก็ได้ — ข้ามคู่มือนี้ทั้งฉบับ**
> ในหน้า Dashboard ทุกข่าวที่มีแคปชันจะมีปุ่ม **📋 คัดลอกโพสต์** กดแล้วได้ แคปชัน + แฮชแท็ก + ลิงก์ ไปวางบน Facebook เองได้ทันที เสร็จแล้วกด **📝 โพสเองแล้ว** เพื่อไม่ให้ข่าวค้างอยู่ในคิว
> ตั้ง token เมื่อต้องการให้ระบบโพสให้อัตโนมัติหรือตั้งเวลาโพสล่วงหน้าเท่านั้น

**สิ่งที่จะได้เมื่อทำครบ (ใส่ทั้ง 2 ค่าในหน้า "จัดการหัวข้อ" ของแต่ละหัวข้อ):**
1. `Facebook Page ID` — id ของเพจปลายทาง
2. `Page Access Token` — token สำหรับโพส

> 🔐 **ทำไม token อยู่ในหน้าจัดการหัวข้อ ไม่ใช่ในไฟล์ config:** ระบบรองรับหลายบัญชี แต่ละบัญชีมีเพจ Facebook และ token ของตัวเอง จึงเก็บ token แยกต่อหัวข้อ (scope ตามเจ้าของ คนอื่นเห็น/ใช้ไม่ได้) ระบบจะไม่ส่ง token กลับมาแสดงอีกหลังบันทึก — ถ้าอยากเปลี่ยนให้พิมพ์ค่าใหม่ทับ

> ⚠️ **ข้อจำกัดสำคัญ:** Facebook API โพสลง**โปรไฟล์ส่วนตัวไม่ได้** ต้องเป็น **Page** เท่านั้น และคุณต้องเป็นแอดมินของเพจนั้น

---

## ขั้นที่ 1 — เตรียม Facebook Page

ถ้ามีเพจอยู่แล้ว ข้ามไปขั้นที่ 2

1. เข้า https://www.facebook.com/pages/create
2. ตั้งชื่อเพจ เลือกหมวดหมู่ แล้วกด **สร้างเพจ**

## ขั้นที่ 2 — สมัคร Meta for Developers และสร้างแอป

1. เข้า https://developers.facebook.com แล้วล็อกอินด้วยบัญชี Facebook ของคุณ
2. กด **Get Started** (ครั้งแรก) → ยืนยันอีเมล → เลือก role เป็น Developer
3. ไปที่ **My Apps** → **Create App**
4. เลือก use case: **Other** → app type: **Business** → กด Next
5. ตั้งชื่อแอป (เช่น `News Curator`) ใส่อีเมลติดต่อ → **Create App**

> 💡 แอปอยู่ในโหมด **Development** ก็เพียงพอ — โหมดนี้ใช้กับเพจที่เราเป็นแอดมินเองได้เต็มรูปแบบ ไม่ต้องยื่น App Review (App Review จำเป็นเมื่อจะให้คนอื่นใช้แอปเท่านั้น)

## ขั้นที่ 3 — ขอ Page Access Token (แบบไม่หมดอายุ)

ใช้ **Graph API Explorer** (เครื่องมือของ Meta เอง):

1. เข้า https://developers.facebook.com/tools/explorer
2. มุมขวาบน ช่อง **Meta App**: เลือกแอปที่สร้างในขั้นที่ 2
3. ช่อง **User or Page**: เลือก **Get User Access Token**
4. กด **Add a Permission** แล้วเพิ่มสิทธิ์ 3 ตัว:
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
5. กด **Generate Access Token** → Facebook จะเด้งหน้าต่างให้ล็อกอิน/ยินยอม → เลือกเพจที่จะให้แอปเข้าถึง → ยินยอมทุกสิทธิ์
6. ตอนนี้ได้ **User token (อายุสั้น ~1–2 ชม.)** — ต้องแปลงเป็นแบบยาว:
   1. ไปที่ **My Apps → (แอปของคุณ) → App settings → Basic** จด **App ID** และ **App Secret** ไว้
   2. เปิด URL นี้ในเบราว์เซอร์ (แทนค่า 3 จุด):
      ```
      https://graph.facebook.com/v23.0/oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=USER_TOKEN_จากข้อ_5
      ```
   3. ได้ JSON ตอบกลับ — ค่า `access_token` ในนั้นคือ **User token อายุยาว (~60 วัน)**
7. เอา User token อายุยาวไปขอ **Page token**:
   1. เปิด URL นี้ (แทนค่า token):
      ```
      https://graph.facebook.com/v23.0/me/accounts?access_token=USER_TOKEN_อายุยาว
      ```
   2. JSON ตอบกลับจะมีรายการเพจของคุณ — จดไว้ 2 ค่า:
      - `id` = **Page ID** (ใช้ในหน้า "จัดการหัวข้อ")
      - `access_token` = **Page Access Token** ✅ ตัวนี้แหละที่ต้องใช้

   > ⛔ **จุดที่พลาดบ่อยที่สุด — อย่าเอา App ID มาใส่ช่อง Page ID!**
   > ในหน้า Meta for Developers มีเลข ID เต็มไปหมด แต่ **App ID** (จาก App settings → Basic) กับ **Page ID** เป็นคนละค่าโดยสิ้นเชิง หน้าตาเหมือนกัน (ตัวเลขยาว ๆ) จนแยกไม่ออกด้วยตา
   > **Page ID ที่ถูกต้องมีที่มาเดียว: ค่า `id` จาก `/me/accounts` เท่านั้น**
   > ถ้าใส่ App ID จะได้ error code 100 ที่เขียนว่า "Object does not exist" ซึ่งชวนให้เข้าใจผิดว่าเพจไม่มีสิทธิ์

   > ⛔ **จุดพลาดอันดับสอง — User token ≠ Page token**
   > token ที่ Graph API Explorer ให้ตอนกด Generate คือ **User token** เอามาใส่ตรง ๆ จะได้ error code 200 ต้องผ่านข้อ 7 นี้เพื่อแลกเป็น Page token ก่อนเสมอ (วิธีเช็คเร็ว ๆ: เปิด `https://graph.facebook.com/v23.0/me?access_token=TOKEN` ถ้าคืน**ชื่อคน** = User token, ถ้าคืน**ชื่อเพจ** = Page token ✅)
   3. Page token ที่ได้จาก User token อายุยาว **ไม่มีวันหมดอายุ** (จะหมดเมื่อเปลี่ยนรหัสผ่าน Facebook, ถอนสิทธิ์แอป, หรือ Facebook บังคับ logout เท่านั้น)

> 🔍 ตรวจสอบอายุ token ได้ที่ https://developers.facebook.com/tools/debug/accesstoken — วาง token แล้วดูช่อง "Expires" (ควรขึ้น Never)

## ขั้นที่ 4 — ใส่ค่าในระบบ

เปิด Dashboard → หน้า **จัดการหัวข้อ** → กด **แก้ไข** หัวข้อที่ต้องการ แล้วกรอก 2 ช่อง:

1. **Facebook Page ID** = ค่า `id` จากขั้นที่ 3 ข้อ 7
2. **Facebook Page Access Token** = ค่า `access_token` จากขั้นที่ 3 ข้อ 7

กด **บันทึก** — เสร็จแล้วในรายการหัวข้อจะขึ้น "🔑 Access Token: ตั้งไว้แล้ว"

### ✅ ตรวจก่อนโพส: ปุ่ม "🔌 ทดสอบการเชื่อมต่อ"

หลังบันทึก **กดปุ่ม 🔌 ทดสอบการเชื่อมต่อ ที่หัวข้อนั้นก่อนเสมอ** — ระบบจะยิงถาม Facebook แบบอ่านอย่างเดียว (ไม่โพสอะไรทั้งสิ้น) แล้วบอกเป็นภาษาไทยว่าติดตรงไหน แทนที่จะต้องไปเดาจาก error code ตอนกดโพสจริง

ตรวจให้ 2 ชั้น:

| สิ่งที่ตรวจ | ตอบว่าอะไรได้บ้าง |
|---|---|
| **ID ปลายทาง** | เป็นเพจจริงและชื่ออะไร / มีอยู่จริงแต่**ไม่ใช่เพจ (น่าจะเป็น App ID)** / หาไม่เจอ (ID ผิด หรือเพจไม่ได้ให้สิทธิ์) |
| **ชนิดของ token** | เป็น Page token ของเพจนี้ ✅ / เป็น **User token** ต้องแลกก่อน / เป็น Page token แต่**ของคนละเพจ** / หมดอายุ |

ขึ้น ✅ ทุกข้อเมื่อไหร่ค่อยไปขั้นที่ 5

> 🔒 token เก็บในฐานข้อมูลแบบผูกกับบัญชีคุณ ระบบจะไม่แสดง token กลับมาอีก (ช่องจะว่างพร้อมข้อความ "ตั้งไว้แล้ว") ถ้าต้องการเปลี่ยนให้พิมพ์ค่าใหม่ทับแล้วบันทึก ถ้าเว้นว่างไว้ = คงค่าเดิม
> 🔒 ห้ามส่ง token ให้ใคร — ใครมี token นี้ = โพสลงเพจคุณได้

## ขั้นที่ 5 — ทดสอบโพส

1. เปิด Dashboard หน้าแรก → ฟิลเตอร์สถานะ **อนุมัติแล้ว** (ถ้ายังไม่มี ให้อนุมัติข่าวสัก 1 ชิ้นก่อน)
2. กด **🚀 โพสทันที**
3. ถ้าสำเร็จ สถานะจะเปลี่ยนเป็น "โพสแล้ว" พร้อมลิงก์ **ดูโพสต์บน Facebook**
4. ลอง **🕐 ตั้งเวลาโพส** ด้วย — เลือกเวลาล่วงหน้าอย่างน้อย 10 นาที โพสต์จะไปรออยู่ใน Planner ของเพจ (ดูได้ที่ Meta Business Suite → Planner) และเผยแพร่เองตามเวลา

## แก้ปัญหาที่พบบ่อย (Troubleshooting)

> 💡 **ทางลัด: เจอ error อะไรก็ตาม ให้กดปุ่ม "🔌 ทดสอบการเชื่อมต่อ" ในหน้าจัดการหัวข้อก่อน** — มันจะบอกสาเหตุตรง ๆ เป็นภาษาไทย เร็วกว่านั่งไล่ตารางนี้

| อาการ / error | สาเหตุ | วิธีแก้ |
|---|---|---|
| `code 190` — token expired/invalid | token หมดอายุ ถูกเพิกถอน หรือเปลี่ยนรหัสผ่าน Facebook | ทำขั้นที่ 3 ใหม่ทั้งหมด |
| `code 200` — "requires pages_manage_posts as an admin" | **สาเหตุที่พบบ่อยสุด: ใช้ User token แทน Page token** (รองลงมา: ไม่ได้ให้สิทธิ์ `pages_manage_posts` หรือไม่ได้ติ๊กเลือกเพจตอนยินยอม) | เช็คด้วย `/me?access_token=TOKEN` — ถ้าคืนชื่อคน = ยังเป็น User token ให้ไปแลกที่ `/me/accounts` (ขั้นที่ 3 ข้อ 7) แล้วเอา `access_token` ของเพจมาใส่ทับ |
| `code 100` — "Object with ID '...' does not exist, cannot be loaded due to missing permissions, or does not support this operation" | ข้อความนี้กำกวมมาก เกิดได้ 3 กรณี: **(1) เอา App ID มาใส่ช่อง Page ID** (พบบ่อยสุด) (2) Page ID พิมพ์ผิด (3) เพจนี้ไม่ได้ถูกเลือกตอน Generate token | กดปุ่มทดสอบการเชื่อมต่อ — มันแยก 3 กรณีนี้ให้ ถ้าเป็นกรณี (1) จะบอกว่า "มี object อยู่จริงแต่ไม่ใช่เพจ" ให้เอา `id` จาก `/me/accounts` มาใส่แทน |
| `code 100` — "Tried accessing nonexisting field (...)" ตอนกดทดสอบ | ID ที่กรอกไม่ใช่เพจ (เป็นแอปหรือออบเจกต์ชนิดอื่น) | ใช้ค่า `id` จาก `/me/accounts` เท่านั้น |
| ผลทดสอบว่า "เป็น Page token แต่ของคนละเพจ" | มีหลายเพจ แล้วหยิบ `access_token` มาจากคนละบล็อกกับ `id` ใน JSON ของ `/me/accounts` | ใน JSON ต้องหยิบ `id` กับ `access_token` **จากบล็อกเดียวกัน** ของเพจนั้น |
| ข้อความ "ยังไม่ได้ตั้ง Facebook Page Access Token" | หัวข้อยังไม่มี token | ใส่ token ในหน้าจัดการหัวข้อ |
| ข้อความ "หัวข้อนี้ยังไม่ได้ตั้ง Facebook Page ID" | หัวข้อยังไม่ผูกเพจ | ใส่ Page ID ในหน้าจัดการหัวข้อ |
| ตั้งเวลาแล้ว error เรื่องเวลา | Facebook รับเฉพาะ 10 นาที – 75 วันล่วงหน้า | เลือกเวลาใหม่ในช่วงที่กำหนด |
| โพสขึ้นแต่ preview ลิงก์ไม่สวย | ลิงก์จาก Google News เป็น redirect | ปกติ Facebook resolve ให้เอง ถ้าไม่ขึ้นรอสักครู่หรือโพสใหม่ |

## หมายเหตุเรื่องความปลอดภัยของ token

- Token เก็บในฐานข้อมูลแบบผูกกับหัวข้อของแต่ละบัญชี (scope ตามเจ้าของ) และไม่ถูกส่งกลับมาแสดงที่หน้าเว็บอีกหลังบันทึก
- แต่ละบัญชี/หัวข้อใช้ token ของเพจตัวเอง — ไม่ปนกันข้ามบัญชี
- ถ้าสงสัยว่า token รั่ว: ไปที่ Facebook → Settings → Business Integrations → ถอนสิทธิ์แอป แล้วขอ token ใหม่มาใส่ทับ
- หมายเหตุ: token เก็บเป็น plaintext ในฐานข้อมูล ควรจำกัดสิทธิ์เข้าถึง DB (Turso auth token) ให้รัดกุม
